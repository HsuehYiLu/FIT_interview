# FIT Interview - Junior Data Scientist

Welcome to my repository for the FIT Junior Data Science interview assignment. This project is divided into three main tasks, covering behavioral questions, machine learning, and computer vision. 

**Note:** This is the main repository cover. Detailed codes, explanations, and specific instructions for each task are located in their respective sub-folders.

##  Repository Overview

### [Task 1: General Questions](./Task_1) (20%)
Contains written responses to behavioral and technical interview questions, detailing my preferred modeling languages, practical SQL experience, cross-functional communication skills, and personal strengths/weaknesses.

### [Task 2: Machine Learning](./Task_2) (20%)
A tabular data classification project aimed at predicting a binary target (`Exited`). 
* **Contents:** A Python script (`main.py`) that trains a predictive model.
* **Outputs:** Predicted results, evaluation metrics (e.g., F1 Score, Confusion Matrix), and data visualization plots.

### [Task 3: Computer Vision](./Task_3) (60%)
An image classification project using the PyTorch MNIST dataset. 
* **Contents:** A CNN implementation focused on modeling, optimization, and handling class imbalance.
* **Outputs:** Code, evaluation metrics, and prediction curve visualizations.
